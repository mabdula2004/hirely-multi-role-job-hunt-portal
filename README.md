# Hirely — Multi-Role Job Hunt Portal

Hirely is a React + JavaScript recruitment platform demo with distinct **Candidate, Recruiter, and Admin** workspaces.

## Current product surface

### Candidate
Job discovery, recommendations, saved jobs, applications, interviews, messages, job alerts, career profile, resume center, and candidate-specific settings.

### Recruiter
Job management, ATS applicant pipeline, talent search, interviews, messages, company profile, hiring analytics, job templates, and recruiter/team settings.

### Admin
Users, company verification, job moderation, application oversight, reports, categories & skills, support tickets, analytics, audit logs, and platform controls.

## Stack

- React 18
- JavaScript
- Vite
- Framer Motion
- Lucide React
- Vercel

## Demo data

The current interface uses synthetic job, company, candidate, recruiter, application, message, report, support, and analytics data for product demonstration and QA.
